# Etapa 03 - Frontend Base

## Objetivo
Montar base visual preservando fluxo do Pluvio 2.1.

## Entregaveis
- Layout principal com mapa/listas/formulario.
- Paginas Home, IDF, Auth, Admin, User.
- Componentes base em `components/layout`, `ui`, `map`, `forms`, `reports`.

## Criterio de Conclusao
- Usuario navega por paginas sem erros.
- Fluxo `UF -> Estacao/Localidade -> Calcular` visivel na interface.
