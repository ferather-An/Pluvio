# Etapa 01 - Fundacao do Projeto

## Objetivo
Levantar o esqueleto executavel de frontend e backend.

## Entregaveis
- Frontend Vite com rota inicial e layout base.
- Backend Express com healthcheck e roteamento v1.
- Padrao de pastas validado contra arquitetura.

## Criterio de Conclusao
- `frontend` sobe localmente.
- `server` responde `GET /health`.
