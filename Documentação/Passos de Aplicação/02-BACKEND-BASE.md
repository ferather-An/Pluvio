# Etapa 02 - Backend Base

## Objetivo
Criar API v1 com camadas controller, service, model e middleware.

## Entregaveis
- `server.js` com bootstrap.
- `routes/v1.routes.js` e `routes/admin.routes.js`.
- Controllers iniciais: idf, auth, admin.
- Middlewares: auth e ratelimit.

## Criterio de Conclusao
- Rotas v1 respondendo com contrato minimo JSON.
- Estrutura pronta para acoplar banco e motor de calculo.
