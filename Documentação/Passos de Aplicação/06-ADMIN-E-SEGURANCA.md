# Etapa 06 - Admin e Seguranca

## Objetivo
Criar area administrativa para atualizar dados com controle de acesso.

## Entregaveis
- Login admin e middleware JWT.
- Rotas de importacao e publicacao de dataset.
- Registro em update_log.

## Criterio de Conclusao
- Apenas admin executa import/publish.
- Cada atualizacao gera trilha de auditoria.
