# Etapa 07 - Relatorios e Exportacao

## Objetivo
Gerar saida tecnica para uso em projeto de drenagem.

## Entregaveis
- Relatorio com entrada, intensidade, K/a/b/c, versao e referencia.
- Exportacao JSON e PDF.
- Aviso explicito para calculo interpolado.

## Criterio de Conclusao
- Usuario exporta relatorio completo pela interface.
- API retorna payload padrao rastreavel.
